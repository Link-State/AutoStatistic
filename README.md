# AutoStatistic
### [통계 프로그램]

### 개발 기간
> version 1.0.0 : 2024.08.30 ~ 2024.12.27<br>
> version 2.0.0 : 2025.12.22 ~ 2025.12.28<br>

### 개발 환경
> Python 3.12.6<br>
> openpyxl 3.1.5<br>
> PyQt 5.15.11<br>
> Pandas 2.3.3<br>
> Pyinstaller 6.17.0<br>

### 설명
+ 동기
  + 지역아동센터 국가근로장학 중, 설문지를 바탕으로 기초적인 통계를 산출하는 프로그램 제작
  + 이와 관련된 행정 업무 간편화 목적
+ 기획
  + version 1.0.0
    + 빠른 개발을 위해 Python 채택
    + openpyxl을 이용한 설문지 데이터 크롤 및 통계 작성
    + PyQt5로 UI 설계
  + version 2.0.0
    + openpyxl과 pandas를 이용하여 version 1.0.0의 전반적인 코드를 간소화
